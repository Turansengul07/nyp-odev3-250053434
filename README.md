## Proje Açıklaması
Toros Efsaneleri, Java 17 kullanılarak geliştirilen bir karakter sistemi projesidir. Projede nesne yönelimli programlamanın kapsülleme, kalıtım, metot ezme, IS-A, HAS-A ve DRY ilkeleri ele alınmaktadır.

## Sınıflar
- Lonca: Lonca bilgileri ve duyuruları.
- Silah: Hasar ve dayanıklılık sistemi.
- Karakter: Ortak karakter özellikleri.
- Savasci: Zırh sistemi.
- Buyucu: Mana ve büyü sistemi.
- Okcu: Ok ve menzilli saldırı sistemi.
- Suikastci: Gizlenme ve özel saldırı sistemi.
- Main: Programın çalıştırılması ve örnek senaryo.

## Kullanılan Teknolojiler
- Java 17
- Git ve GitHub

## Çalıştırma

Proje ana dizininde terminal açılarak:

```bash
javac -encoding UTF-8 -d out src/toros/*.java
java -cp out toros.Main
```
